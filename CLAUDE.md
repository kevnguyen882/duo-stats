# Branches

Steph (Kevin's duo partner) works on the `steph` branch. When you're working with Steph, in any session:

- Switch to `steph` before making changes (`git fetch origin steph && git checkout -B steph origin/steph`; a fresh
  clone may track only `main`), and commit and push there. Never to `main` or a new branch unless she asks.
- If you can't tell whether you're working with Steph or Kevin, ask before committing.

Kevin's own work isn't affected by this.
