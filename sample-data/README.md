# Sample data

A snapshot of Kevin's `data/` folder from Oct 27, 2026 (games, grades, augments, utopia, settings),
so the app has something to show on another computer. The LAN PIN secret is left out, and the Riot key
was never in here (it lives in the Mac's Keychain).

To use it, copy it into place from the project folder:

```
cp -R sample-data data
```

`data/` is gitignored, so anything the app saves after that stays on your computer.
